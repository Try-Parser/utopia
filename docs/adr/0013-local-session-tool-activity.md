# 0013: Place local sessions by structured tool activity

Status: accepted for local implementation, 2026-10-13.

The user requested automatic connection of real local coding activity after detecting that working sessions were shown walking in the corridor. Under that authorization, the coordinator adopts a bounded metadata projection of locally accessible structured events. This extends the reported-role model in [0011](0011-autonomous-agent-office.md); native authorization and computer preview boundaries in [0012](0012-workstation-code-and-app-preview.md) remain unchanged.

Read fixed event/tool categories and lifecycle signals from bounded primary session tails. Exact live Claude session correlation is required. Fresh structured Codex turns may be observed without a process link, which is disclosed. A tool-category department means an activity placement, never an inferred specialist identity. Explicit role heartbeats retain precedence. Session IDs and activity references remain opaque; no prompts, arguments, outputs, commands, code or input file paths are projected. Do not invoke a provider or change its configuration.

Adapter-only detection preserves privacy but leaves ordinary working sessions unclassified. Using process presence, file freshness or prompt interpretation would invent activity. Unbounded transcript reading would add unnecessary privacy and performance cost. The bounded allowlist retains source provenance and unknown states when evidence is unavailable; it does not infer collaboration or meetings.

The contract is in [Agent World SPEC](../../apps/agent-world/SPEC.md). Docker discovery/model and actual HTTP/Chromium journeys must verify classification, completion, expiry, malformed/bounded input, adapter precedence and private-field exclusion. Independent correctness, QA and security attestations are required before delivery. Revisit if provider event schemas change, supported tools expand, or exact subagent identities become available. This record grants no deployment or paid-provider authorization.
