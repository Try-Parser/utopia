# Observed tool smoke and local control panel

Download [the HTML control panel](control-panel.html) and open it locally. It displays [the actual content-free summary](telemetry-summary.json) derived from [the recorded trace](tool-smoke.jsonl).

On 08 October 2026 the coordinator exercised the real Docker gateway against a disposable sanitized fixture: an allowed README read passed and a secret-path request was denied. The recorder observed elapsed/wait time and both tool outcomes. The fixture contents are synthetic; the tool execution and timing are observed. No model ran, no human-graded campaign was submitted, and token/cost fields remain unknown. One expected denial does not measure model-level prompt-injection resistance.

The panel is standalone HTML with no external scripts/assets or live connections. It summarizes supplied evidence; it does not grant permissions, launch agents or enforce isolation itself. Use the [measurement runbook](../../../skills/ai-evaluation/references/measurement.md) for a real private campaign and [gateway runbook](../../../skills/autonomous-development/references/tool-gateway.md) for approved routed operations.

Independent final checks and review records remain in the coordinator's external run directory. This demonstration is separate from those software regression results and from historical verification charts.
